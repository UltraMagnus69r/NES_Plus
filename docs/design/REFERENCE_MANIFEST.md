# R2.3 reference manifest

These images are visual references for Nesticles Design Language 2.0. They are not production assets, not cartridge graphics, and not evidence that a depicted character has been reconstructed.

The owner supplied three images with the R2.3 assignment. They were not separate files named `UNMAKER_LAB_V2_MOCKUP.png`, `MAKER_ENGINE_V2_MOCKUP.png`, and `MAKER_AND_DESIGN_BOARD_ORIGINAL.png`. This folder keeps the supplied images under the closest names. A standalone full-window Maker Engine file was not in the assignment attachments. Maker composition is the lower half of the composite and the lower-right panel of the design board.

| File | What it is | What it is not |
| --- | --- | --- |
| `references/UNMAKER_LAB_V2_MOCKUP.jpg` | UnMaker Lab Discover composition: header, left navigation, wrapping cards, Goomba inspector. | A screenshot of this build. Permission to draw completed Mario, Luigi, or Koopa art. |
| `references/MAKER_AND_UNMAKER_COMPOSITE.jpg` | Combined UnMaker gallery and Maker course composition, including a floating parts tray, course canvas, and Game Style chip. | A saved course. The pictured level is concept art. |
| `references/DESIGN_LANGUAGE_BOARD.jpg` | Token board: color, type, radius, spacing, states, and both workspace personalities. | A second design direction. The written contract in `NESTICLES_DESIGN_LANGUAGE_V2_0.md` wins when a poster detail and the written behavior disagree. |

Depicted Nintendo characters in these images are concept-art stand-ins. The application may show a reconstructed Goomba only from the existing assembler. Every other candidate stays an honest placeholder or source tile.

Do not copy these files into a release archive. Do not load them as sprite textures.
