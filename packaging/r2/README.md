# Nesticles R2 Goomba reconstruction test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R2.2-CharacterPresentation-linux-x86_64.tar.gz
cd Nesticles-R2.2-CharacterPresentation-linux-x86_64
./nesticles
```

Open a verified Super Mario Bros. cartridge in UnMaker and start the investigation. Discover lists compact cards. Open Goomba in Review to see the large walk and Defeat / Stomped preview. Approve & Save Goomba is on that Review screen. The cartridge is not stored in the project. Reopen the project and press Play. The walk colors are review colors, not a verified original palette.
