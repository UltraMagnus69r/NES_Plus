# Nesticles R2 Goomba reconstruction test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R2-GoombaReconstruction-linux-x86_64.tar.gz
cd Nesticles-R2-GoombaReconstruction-linux-x86_64
./nesticles
```

Open a verified Super Mario Bros. cartridge in UnMaker, start the investigation, and open Goomba. Approve and save writes the character into the project. The cartridge is not stored in that file. Reopen the project and press Play. The walk colors are review colors, not a verified original palette.
