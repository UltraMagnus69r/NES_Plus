# Knowledge export

Approving a reviewed object stores a recipe in this alpha's library:

`~/.local/share/nesticles/nesticles/alpha2-phase9.1/knowledge.nknowledge`

A later extraction of the same payload digest proposes that recipe. A different payload does not inherit it as a verified match. A grouping you rejected is not offered again as a new answer when the tiles are unchanged.

Export knowledge package writes `export.nknowledge` in that library folder. Nothing is uploaded.

Import knowledge package reads a file you choose. The import rejects a file over 2 MB, a wrong schema, a path containing `..`, or a recipe that exceeds the sprite limits. Imported recipes stay in this alpha's library.

A new alpha uses a different folder and starts empty. This build does not delete another alpha's folder, your exported packages, or the API key.
