# Nesticles Alpha 2 — Phase 9.1 test candidate

This is a test candidate, not a finished Phase 9.1 acceptance build. The user's Super Mario Bros. cartridge and a live OpenAI key were not available when this package was built.

UnMaker Lab now has a home screen, a hash-checked NES extractor, a review queue, a tile puzzle, a local recipe file, content packages, and an OpenAI settings page. Maker Engine still places parts and plays courses.

Flip Workspace, or the UnMaker Lab button, opens the home screen. Unsaved work is kept. Choose Disassemble a ROM, Open a saved creation, or Start a new creation.

The application starts fullscreen.

See QUICKSTART.md, ROM.md, API.md, KNOWLEDGE.md, and LIMITATIONS.md.
