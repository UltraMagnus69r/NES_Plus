# Nesticles R2.3 Design Language 2.0 test candidate

Linux x86_64. Run it from the extracted folder. Do not install it.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R2.3-DesignLanguage-linux-x86_64.tar.gz
cd Nesticles-R2.3-DesignLanguage-linux-x86_64
./nesticles
```

The window opens decorated. UnMaker Lab is the yellow-egg workspace. Maker Engine is the castle workspace. Discover scrolls vertically. Review has one Approve & Save Goomba action. Maker Test Play runs the existing course runtime. Classic 8-bit is the only Game Style that can be selected.

R2.3 is not accepted. R3 has not started.
