# Nesticles R1.3 unified interface test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R1.3-UnifiedInterface-linux-x86_64.tar.gz
cd Nesticles-R1.3-UnifiedInterface-linux-x86_64
./nesticles
```

UnMaker Lab and Maker Engine share the window and the white theme. F6 switches workspaces. Source tiles, audio, the library, and export open from the UnMaker stage that owns them.
