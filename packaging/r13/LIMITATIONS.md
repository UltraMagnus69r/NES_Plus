# R1.3 unified interface

This archive is a test candidate. It is not an accepted build.

UnMaker Lab and Maker Engine share one white desktop theme. The old Source Tools destination is not a separate shell. Its screens open from the stage that owns the job.

Review colors are still a display aid. They are not a verified original palette. An HTTP 403 is still a site block.

Goomba is still not a reconstructed animation. Approval does not publish a sprite. Package export still paints the first frame only. Phase 9.1 is not accepted. Phase 10 is not included. R2 has not started.

The application starts in a decorated window. Fullscreen is optional.
