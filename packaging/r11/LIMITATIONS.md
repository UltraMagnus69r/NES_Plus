# R1.1 window correction

This archive launches as a decorated desktop window. It is not an accepted build.

Fullscreen is optional. It starts only from the Menu command or F11. Escape leaves fullscreen. The application does not request fullscreen at startup.

Window size and position are stored in the OS data directory for `nesticles-window`. That file is not the alpha library and does not delete older alphas, projects, or keys.

The reconstruction limits from the R1 studio still apply. Goomba is not an animated asset. Approval does not publish a sprite. Phase 9.1 is not accepted. Phase 10 is not included.
