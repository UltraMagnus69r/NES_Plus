# Nesticles R1.1 desktop window test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R1.1-DesktopWindow-linux-x86_64.tar.gz
cd Nesticles-R1.1-DesktopWindow-linux-x86_64
./nesticles
```

The window has the system title bar. Minimize, maximize, restore, and close are the desktop's own buttons. UnMaker Lab and Maker Engine share this window. Flip does not enter fullscreen.
