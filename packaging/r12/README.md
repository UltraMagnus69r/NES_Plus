# Nesticles R1.2 review usability test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R1.2-ReviewUsability-linux-x86_64.tar.gz
cd Nesticles-R1.2-ReviewUsability-linux-x86_64
./nesticles
```

The preview has review-color buttons. The label says the colors are not a verified original palette. If a reference site returns HTTP 403, continue without a reference, import a local image, or fetch the field as a direct image.
