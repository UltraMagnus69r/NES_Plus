# R1.2 review usability

This archive is a test candidate. It is not an accepted build.

Source-tile previews can use review colors. Those colors are a display aid. They are not a verified original palette, and they are not written into an exported sprite.

A reference site that returns HTTP 403 is reported as a blocked automated request. The application does not work around that block.

Goomba is still not a reconstructed animation. Approval does not publish a sprite. Phase 9.1 is not accepted. Phase 10 is not included. R2 has not started.

The application starts in a decorated window. Fullscreen is optional.
