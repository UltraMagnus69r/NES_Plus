# Nesticles R1 UnMaker studio test candidate

Linux x86_64. Run it from the extracted folder. Do not install it over an older alpha.

```sh
cd "$HOME/Downloads"
tar -xzf Nesticles-R1-UnmakerStudio-linux-x86_64.tar.gz
cd Nesticles-R1-UnmakerStudio-linux-x86_64
./nesticles
```

UnMaker Lab opens from Maker Engine. The studio can open a cartridge, run the local investigation, and show source tiles for a documented candidate. It does not publish a reconstructed Goomba. See LIMITATIONS.md.

The file name of a ROM is not its identity. A reference URL is optional and is not fetched until you press Fetch reference.
