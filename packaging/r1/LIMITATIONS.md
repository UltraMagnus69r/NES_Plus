# R1 test candidate limitations

This archive is the UnMaker studio shell. It is not an accepted R1 build, and it is not a finished reconstruction of Super Mario Bros.

- Approving a candidate changes a review flag. It does not create a sprite, an animation, or a library package.
- Package export still paints only the first frame. That export is not offered as a finished asset.
- A named Goomba can show source tiles from the cartridge. Those tiles are not a reconstructed animation. Play stays off.
- Mario and Luigi have no tile mapping in the profile.
- Palette and timing are unverified. Source tiles use a gray ramp.
- The extraction session is kept in memory. Saving the project does not store it or the ROM.
- Reference pages are not compared with ROM tiles. Fetching one is optional and does not send the ROM.
- Live OpenAI is not part of this studio path.
- Godot preview does not play Phase 9 clips. Godot 4.7.2 was not required for this package.
- Maker Engine keeps its previous appearance. New Maker features are not in this build.
- Historical Phase 9.1 is not accepted. Phase 10 is not started.
